# Battery Smart

> Battery Smart is India's largest battery-swapping network for electric two- and
> three-wheelers, founded in 2019 by Pulkit Khurana and Siddharth Sikka and operated from
> New Delhi by Upgrid Solutions Private Limited and Upgrid Electrilease Private Limited.
> Local businesses — kirana stores, petrol pumps, neighbourhood shops — host swap points
> where a driver exchanges a depleted lithium-ion pack for a charged one in roughly two
> minutes, paying per swap instead of buying the battery with the vehicle. The network is
> concentrated in Delhi NCR, Mumbai, Bengaluru, Hyderabad, Jaipur and Lucknow.

## Status

Battery Smart publishes **no public API**, no developer portal, no API reference, no SDK and
no machine-readable contract. As of 2026-08-06, probes on `www.batterysmart.in` for
`/llms.txt`, `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`,
`/api-docs`, `/redoc`, `/graphql`, `/.well-known/security.txt`,
`/.well-known/agent-card.json`, `/.well-known/agent.json`,
`/.well-known/openid-configuration`, `/.well-known/oauth-authorization-server`,
`/.well-known/oauth-protected-resource`, `/.well-known/api-catalog` and
`/.well-known/ai-plugin.json` all returned 404, and `api.`, `docs.` and `developer.`
subdomains of `batterysmart.in` do not resolve in DNS.

The company's software ships only as two end-user Android applications. Their production
backend is `api.upgrid.in` — the root returns `{"message":"Battery Smart API"}` and
`/health` reports SQL/Redis/Kafka/Mongo status — but it is undocumented: every spec path on
that host returns a JSON 404 and no reference, schema or authentication guide is published
for it anywhere. This file is generated by API Evangelist from the catalog profile; it is
not published by Battery Smart.

## Applications

The only shipped software surface. These are end-user apps, not developer SDKs.

- [Battery Smart - Driver](https://play.google.com/store/apps/details?id=com.batterysmart.driver): Android app for drivers — find stations, swap, pay.
- [Battery Smart - Partner](https://play.google.com/store/apps/details?id=com.batterysmart.partner): Android app for station hosts — run swaps and settle earnings to a digital wallet.
